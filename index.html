Найчастіша причина — у репозиторій завантажено не всі файли. Перевірте, що поруч з index.html лежать: app.js, engine.js, store.js, ui.js, charts.js, assistant.js, sheets.js, view-home.js, view-compare.js, view-calendar.js, view-savings.js, view-settings.js, styles.css, sw.js і manifest.webmanifest.

Якщо ви відкрили index.html прямо з «Файлів» на телефоні — модулі не працюють без вебсервера. Відкрийте адресу GitHub Pages.
